# ANDRPROD

**Единый центр управления онлайн-источниками для Lampa.**

Текущая версия исходного файла: **3.1.0**

## Файл плагина

- [Andrprod.js](./Andrprod.js)

## Raw URL

```
https://raw.githubusercontent.com/Fikus-sup4ik/andrprodd/main/Andrprod.js
```

## О проекте

ANDRPROD предназначен для объединения поиска и управления источниками онлайн-кинотеатров в Lampa. Поддержка конкретных источников зависит от реализации адаптеров и совместимости с установленными плагинами Lampa.

## Важно

Это репозиторий исходного кода. Наличие файла в репозитории само по себе не подтверждает работоспособность всех адаптеров или совместимость со всеми сборками Lampa. Проверяйте работу на своей установке.
